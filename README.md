О проекте

F1 Forum — это веб-приложение, созданное для объединения фанатов Формулы-1. Платформа сочетает в себе классические возможности дискуссионного форума с интеграцией актуальных данных о гонках, пилотах и командах через публичное API.
Основные возможности


Гость - Просмотр тем, чтение обсуждений, календарь Гран-При, результаты гонок, регистрация 
Пользователь Создание тем, комментарии, лайки, редактирование своего контента, система жалоб 
Модератор Обработка жалоб, выдача предупреждений, блокировка пользователей, управление контентом 
Администратор Управление ролями, резервное копирование БД, просмотр статистики и логов 

Интеграция с данными Формулы-1

- Получение актуальных данных о сезоне через Jolpi API
- Автоматическое отображение результатов Гран-При
- Статистика пилотов и команд


Технологический стек

Frontend Vue.js 3, Pinia (state management), Vue Router, Axios 
Backend Node.js, Express.js 
Database PostgreSQL 16 
Authentication JWT, bcrypt 
Testing Jest, Supertest 
Tools Draw.io (UML/IDEF0), Figma (UI/UX)

Архитектура

Проект построен по модульному принципу:

f1forum/
├── backend/
│   ├── controllers/    # Обработчики запросов
│   ├── models/         # Модели данных (User, Topic, Comment, etc.)
│   ├── routes/         # API маршруты
│   ├── middleware/     # Аутентификация, валидация
│   ├── tests/          # Jest + Supertest тесты
│   └── server.js       # Точка входа
├── frontend/
    ├── src/
    │   ├── components/ # Vue компоненты
    │   ├── views/      # Страницы приложения
    │   ├── stores/     # Pinia хранилища
    │   ├── services/   # API сервисы
    │   └── router/     # Маршрутизация
    └── public/         # Статика



База данных

Спроектирована в 3 нормальной форме (3NF), содержит 16 таблиц:

- `users` — пользователи, роли, статусы
- `topics`, `comments` — основной контент
- `topic_likes`, `comment_likes` — система лайков
- `reports`, `moderator_actions` — модерация
- `grand_prix` — данные о Гран-При
- `notifications`, `user_warnings` — уведомления и предупреждения
- `activity_logs` — аудит действий

Установка и запуск

bash
# Клонирование репозитория
git clone https://github.com/Mikhail1708/f1forum.git
cd f1forum

# Установка зависимостей бэкенда
cd backend
npm install

# Настройка БД (создайте базу и настройте .env)
createdb f1_forum
cp .env.example .env  # и заполните своими данными

# Выполнение миграций
npm run migrate

# Запуск сервера
npm run dev

# Установка зависимостей фронтенда (новый терминал)
cd ../frontend
npm install
npm run dev


Приложение будет доступно:
- Frontend: `http://localhost:5173`
- Backend API: `http://localhost:3000`

Безопасность

- JWT-аутентификация (токен живёт 60 минут)
- Хеширование паролей (bcrypt)
- Защита от XSS и SQL-инъекций
- Валидация входных данных на клиенте и сервере
- HTTPS (в production)

Производительность

- Поддержка до 500 активных сессий
- До 100 RPS (запросов в секунду)
- Среднее время отклика < 200 мс
